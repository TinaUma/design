AI Vibe Station — сайт-визитка вместо списка репозиториев

GitHub-профиль — это не портфолио. HR открывает его и видит список репозиториев. Нужна страница, которую можно открыть в браузере, понять за 30 секунд кто этот человек и сразу написать. Вот она.

Как это выглядит

Тёмная и светлая секции на одном экране — герой-блок с фото и данными, и сразу переход к стеку. Оранжевый акцент (#FF5500), IBM Plex Mono для меток, Vitruvius как манифест.

Задача

GitHub — не портфолио

Специалисту, который не занимается дизайном, сделать себе нормальный сайт — отдельная задача. Чаще всего её откладывают. А список репозиториев без контекста работает плохо.

GitHub-профиль
  • Надо открывать каждый репозиторий отдельно
  • Непонятно что человек умеет и чем занимается
  • Нет фото, нет контекста, нет приоритетов
  • Везде одинаковый интерфейс — нет характера
Сайт-визитка
  • 30 секунд — и понятно кто человек и чем занимается
  • Приоритеты расставлены: главный проект выделен
  • Личность считывается через дизайн и текст
  • Кнопка «Написать» — прямо на экране
Содержание

Шесть проектов — один экран

На сайте выведено 6 проектов в тёмной грид-сетке. Flagship — SignDrop — выделен особо. Каждая карточка открывается в демо или в GitHub.

01 SignDrop ★ Flagship PDF-подпись прямо в браузере. Библиотека подписей, удаление фона, история. Полностью локально.
02 WB Margin Analyzer SaaS Загружаешь Excel → система считает маржу по каждому товару + AI-диагноз от Claude.
03 Dreamora Voice AI Telegram-бот соматической расшифровки снов. Голос или текст → Groq Whisper → Claude.
04 Channelyze Product Парсинг Telegram-канала → каталог услуг → квиз-воронка → бот с оплатой.
05 VisionStyle Vision AI Загружаешь фото → стиль-паспорт: палитра HEX, материалы, настроение.
06 h3llo-vpn Infra Переиспользуемый VPN-прокси контейнер. Любой Docker-сервис получает прокси тремя строками.
Процесс

Vibe-coding с Claude Code

Сайт собран в Claude Code + TAUSIK. Задачи, сессии, quality gates — всё как в продуктовой разработке, только предмет — собственное портфолио.

Astro выбран за статичность (GitHub Pages, нет бэкенда) и скорость сборки. Tailwind CSS v4 — последняя версия с нативным CSS-движком. Дизайн-решения принимались итеративно: сначала структура секций, потом визуальный язык.

Результат

Живёт на GitHub Pages — бесплатно и навсегда

Деплой через GitHub Actions: push в main → сборка → Pages. Без сервера, без затрат. Это же используется как шаблон для портфолио специалистов — когда нужна такая же визитка, но с другим именем и проектами.
